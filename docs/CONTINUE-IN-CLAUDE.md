# Передача в Claude или другой coding agent

Открой репозиторий в Claude Code либо среде, где ИИ может читать/менять файлы и запускать команды. Для отправки изменений нужны права записи в GitHub. Ссылка в обычном чате сама по себе таких прав не даёт.

Скопируй этот запрос:

> Продолжи разработку MEERKAT: https://github.com/kocer6/MEERKAT. Сначала прочитай CLAUDE.md, AGENTS.md, PLAN.md и HANDOFF.md. Проверь текущую ветку, git status и последние commits. PLAN.md содержит общий план и выполненные пункты, HANDOFF.md — точное место остановки, проверки и следующую задачу. Выполняй следующий незавершённый пункт по актуальному коду, не начинай проект заново. Приоритет — двухдневный paper MVP; полный V1 шире текущего релиза. После каждого законченного блока обновляй PLAN.md и HANDOFF.md, выполняй соответствующие проверки, коммить и отправляй изменения в этот репозиторий. Push разрешён. Не отправляй секреты и runtime data. Перед завершением сессии оставь точное описание того, что работает, что не работает и какую операцию выполнить следующей. Если доступ к записи или запуску команд отсутствует, скажи об этом, не выдавая план за выполненную работу.

Не копируй отдельный старый статус из чата: актуальную точку продолжения нужно читать из репозитория. Основная ветка — main; если HANDOFF.md указывает WIP ветку, сначала проверь её и описанные незавершённые изменения.
